**Aggregate failure-category breakdown** (from this run, categories only — no row-level
question/query text): the dominant failure mode was structural under-traversal — the model
collapsing multi-hop patterns into fewer hops and inventing or dropping relationship types
(`rel_types differ`, `hop_count differs`, `varlen differs`) — followed by wrong/missing
labels and return columns (`labels differ`, `return columns missing from prediction`).
Aggregation-logic errors were comparatively rare. A handful of predictions also produced
outright Cypher type errors (e.g. treating a path expression where a scalar was expected).
